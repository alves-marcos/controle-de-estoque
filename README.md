# 📦 Projeto Controle de Estoque

## 📖 Sobre

Sistema de gerenciamento de estoque desenvolvido em **Java** com o objetivo de praticar os principais conceitos da **Programação Orientada a Objetos (POO)**, organização em camadas e boas práticas de desenvolvimento.

Durante o desenvolvimento deste projeto foram aplicados os seguintes conceitos:

* Instanciação de objetos
* Encapsulamento
* Métodos
* Sobrecarga de métodos
* Definição de responsabilidades entre classes

---

## ✨ Funcionalidades

* Cadastro de produtos
* Atualização da quantidade em estoque
* Exibição do resumo dos produtos cadastrados
* Cadastro de produtos no estoque
* Listagem dos produtos cadastrados
* Busca de produtos por ID ou nome
* Remoção de produtos do estoque

## ▶️ Como executar o projeto

1. Clone este repositório.
2. Abra o projeto na IDE de sua preferência (IntelliJ IDEA, Eclipse ou VS Code).
3. Execute a classe `Main.java`.
